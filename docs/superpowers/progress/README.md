# Implementation progress

This directory tracks active implementation work at a smaller granularity than
design specs and implementation plans.

Every topic uses exactly one status:

- `pending` — planned but not started.
- `implementing` — code or verification is actively in progress.
- `implemented` — the topic's code, automated checks, and required documentation
  are complete.

Large features get their own directory with an index and focused topic files.
The index is the current source of truth for overall status.
